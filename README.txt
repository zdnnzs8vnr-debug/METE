MEATBAG — istruzioni

1. Carica tutto su GitHub (repo pubblico).
2. Settings -> Pages -> branch main, cartella root.
3. Se hai un dominio: Settings -> Pages -> Custom domain, e sul registrar
   punta un CNAME verso TUONOME.github.io
4. Martedì modifica SOLO le 3 righe in cima allo <script> di index.html:
   LAUNCH, PUBLISHED, CA.
5. Non cambiare i nomi dei file in assets, o le immagini spariscono.
